一、为什么现在 ChatGPT Pro 分出了 5x / 10x / 20x / 25x 这么多档？

随着深度推理模型与 Codex 云端编程助手对算力消耗的拉开，单一的月卡已经无法满足不同强度的用户。目前在售的 Pro 体系按额度档位细分为四档：

  • Pro 5x（Standard 档）：定位在 Plus 与重度 Pro 之间。如果你每天用深度推理或 Codex 经常遇到「达到上限需等待重置」，但又用不完上千元的额度，Pro 5x 是最稳的甜点档。
  • Pro 10x：介于 5x 与 20x 之间的过渡档。它最大的价值不是裸买，而是支持已有 Plus 或 Pro 5x 账号中途直接升级。
  • Pro 20x（More 档）：全天候程序员与重度研究员的主力档。注意看价格：Pro 10x 是 ¥1,235.9，而 Pro 20x 只要 ¥1,249（站内卡付款 ¥1,259.9），两者差价仅十几块钱！因此只要你是无订阅的干净账号，闭眼直接买 Pro 20x 最划算。
  • Pro 25x（Max 顶配档）：算力拉满的旗舰档，适合多任务并发跑满全天的工程团队或重度科研场景。

常见问题

ChatGPT Pro 10x（¥1235.9）和 Pro 20x（¥1249）只差 13 块钱，该买哪个？

如果你的账号当前没有生效中的订阅（处于 Free 状态），强烈建议直接买 Pro 20x（¥1249 或 ¥1259.9），多花十几元额度翻倍；只有当你的账号还在 Plus 或 Pro 5x 订阅期内、想直接覆盖升级时，才选支持升级的 Pro 10x（¥1235.9）。

Pro 5x 有 ¥699、¥731.9、¥749.9、¥779.9 好几款，有什么区别？

它们都是充入自己账号的 Pro 5x 月卡（质保 30 天订阅），区别在于上游充值通道与自助核销界面不同。日常选有现货的低价款即可；需要后续补差升级选 ¥797.9 独立账单款；需要覆盖未到期订阅选 ¥816.9 款。

充值 Pro 5x / 20x / 25x CDK 需要提供我的 ChatGPT 密码吗？

除标明「代充」的 ¥3499 款外，其余所有标明「CDK 自助充值 / 站内卡付」的款式均只需按教程提取浏览器 Session 配合卡密自助核销，不需要提供账号密码。

之前开过 Plus 或 Pro 的老号能买吗？

只要旧订阅已经自然到期、当前状态变回 Free，且不在 Team 团队空间内、没有用过违规 0 元黑卡，就可以正常购买常规 CDK 充值；若离到期还有 1～3 天，20x 用户可选 ¥1249 临期续费专用款。

如果平时对话够用，只是写代码跑 Codex 不够用，需要升 Pro 吗？
