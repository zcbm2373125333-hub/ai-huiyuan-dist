一、免费版能做什么

按 Anthropic 定价页，免费版已经包含不少功能：网页、桌面和手机端聊天，联网搜索，创建文件和运行代码，跨对话记忆，连接常用应用和工具，Artifacts，语音模式，最多 5 个 Projects，模型可以用 Sonnet 和 Haiku。日常问答、改写、简单分析，免费版完全可以先用起来。

限制主要在用量：按帮助中心，免费版有按会话计算的用量上限，每 5 小时重置；能发多少条消息取决于消息长度、附件大小、对话长度和当时的需求量，没有固定条数。

二、Pro 多了什么

  • 更多用量：定价页 FAQ 写明，Pro 每 5 小时会话的用量至少是免费版的 5 倍；付费档另有每周上限，在 Settings > Usage 可以看到下次重置时间。
  • Claude Code：所有付费档都包含，和聊天共用同一份额度。写代码是很多人升级的主要原因，额度不够时的处理见 Claude Code 额度不够用怎么办。
  • 更多模型：免费版只有 Sonnet 和 Haiku，Pro 可以用 Opus 等更多模型。
  • Research、不限数量的 Projects、Claude in Chrome 与 Microsoft 365、任务托管与定时：都是免费版没有的。
  • usage credits：付费档用完额度后可以开启 usage credits，按 API 标准价继续使用；免费版只能等重置或升级。
