一、两边的编程工具分别包含在哪些套餐里

  • Claude Code：Anthropic 定价页写明 Claude Code 包含在所有付费档（Pro、Max）中，免费版不含。它和 claude.ai 网页、桌面、手机端共用同一份额度：每 5 小时一个会话窗口，付费档另有每周上限。额度用完可以等重置、升级到更高档，或在付费档开启 usage credits 按 API 标准价继续。
  • Codex：ChatGPT 定价页显示 Free、Go 档只有有限的 Codex，Plus 包含 Codex，Pro 为扩展额度。按 OpenAI 帮助中心，Codex 等功能在用完套餐内额度后可以购买 credits 继续，先用套餐内额度再用 credits；客服不能手动重置额度。

两者不冲突：很多人在编辑器里写代码，同时用 Claude Code 或 Codex 处理具体任务。选哪个主要看你更习惯哪套工作流，以及哪边的额度更容易不够用。
