# 千古人物志 · 每日自动制作工作流（精品模式）

每次运行按《选题队列.md》顺序取 N 个人物（默认 10），对每个人物：
1. 写脚本 render_<拼音>.py：本集独立配色 / 章回卡物件 / 2–3 段长镜头 / 48 幕全新画面（不复用前集画面）
2. 自动检查：毛笔字体缺字、画面重复、全场景开头 1200+ 帧出错扫描（有错先修再继续）
3. 抽帧预览检查文字遮挡，修正
4. 完整渲染 93.7 秒 1080×1920 视频 + 分镜预览图
5. 全片每 0.5 秒抽帧复查
6. 发送成品给用户，在队列中打勾
规则：无跳动圆圈；毛笔字不出现「·」；年份与年龄一致；演义/民间传说在竖排注释中标明。
